# Generated outputs

Assignment outputs are grouped by part and section. Part 2A figures and tables live in `part_2/data_validation/`, with descriptive analysis subdirectories. Source-integrity checks remain in the shared `input_validation/` directory.

Selected PNGs and numerical tables are versioned with their producers for review. Other generated files remain ignored. Do not place standalone code copies or dependency files in the shared output index; reusable code belongs in `src/`.

See [Part 2A](../reports/part_2/data_validation/README.md) for methods and commands. Run `python run_all.py --all` to regenerate integrated outputs.
